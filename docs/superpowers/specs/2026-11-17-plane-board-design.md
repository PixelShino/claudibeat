# Доска Plane в claudibeat: дизайн

17.11.2026. Владелец хочет перетаскивать задачи Plane прямо на агентов: задача
попадает в чат, агент её берёт, делает и сам закрывает.

## Кто что делает

- **claudibeat** рисует доску и принимает перетаскивание. В сеть он по-прежнему
  не ходит: данные берёт из папки status-band, действия оставляет там же заявками.
- **мод status-band** уже опрашивает Plane и пишет `board.json`. Теперь он ещё
  выполняет заявки: двигает задачу в Plane, пишет комментарий, отправляет задачу
  в чат через `ccd_session_mgmt.send_message` или открывает новый чат через
  `ccd_session.start_session`.
- **агент в чате** получает задачу обычным сообщением и по правилу из системного
  промпта мода закрывает её через `mcp__status-band__backlog` (move to=done и comment).

## Окно доски

Открывается четвёртым элементом полосы («задачи», счётчик «в работе») и пунктом
«Доска задач» в меню по правому клику. Окно висит над полосой, как окно сессий,
шириной около 1000 DIP.

- Шапка: «Задачи Plane», фильтр проектов (Все, SEO, WEB…), строка свежести
  («обновлено 2 мин назад») или ошибка Plane, кнопка закрытия.
- Три колонки задач: «Не взято», «В работе», «Готово сегодня». Карточка: ключ,
  проект, приоритет точкой, название в две строки; в «В работе» — кому назначена.
- Справа колонка «Агенты»: живые сессии (ждут, готово, в работе, свободны) и
  внизу «Новый агент» с папками проектов.
- Перетаскивание: карточку тянут, за курсором летит её копия, цели подсвечиваются.
  На сессию — назначить; на «Новый агент → папка» — новый чат в этой папке;
  на колонку — сменить статус. Пока заявка выполняется, на карточке «отправляю…»,
  потом строка итога внизу окна.
- Клик без перетаскивания открывает задачу в Plane в браузере.
- Колесо листает колонку под курсором. Esc и клик мимо закрывают окно.

## Файлы (дополнение к контракту v1)

| Файл | Пишет | Читает |
|---|---|---|
| `board.json` | мод (лидер), как и раньше | claudibeat |
| `assignments.json` | мод (лидер) | claudibeat, мод |
| `requests/<id>.json` | claudibeat; claudibeat же удаляет | мод |
| `replies/<id>.json` | мод, который выполнил заявку; удаляет claudibeat | claudibeat |

`id` — `cb-<ms>-<4 hex>`. Заявки:

```json
{"v":1,"id":"cb-1794930000000-a1f3","at":1794930000000,"by":"claudibeat",
 "kind":"assign","task":"WEB-281","target":{"session":"local_<uuid>"}}
{"v":1,"id":"…","at":…,"by":"claudibeat",
 "kind":"assign","task":"WEB-281","target":{"newChat":{"cwd":"D:\\Code\\Projects\\my-app","project":"my-app"}}}
{"v":1,"id":"…","at":…,"by":"claudibeat","kind":"move","task":"WEB-281","to":"todo|doing|done|cancelled"}
{"v":1,"id":"…","at":…,"by":"claudibeat","kind":"refresh"}
```

Ответ: `{"v":1,"id":"…","at":…,"ok":true,"text":"WEB-281 → «Чистка документации»"}`
или `{"v":1,"id":"…","at":…,"ok":false,"text":"Plane недоступен"}`. Текст — короткая
русская строка для владельца.

`assignments.json`:
`{"v":1,"updatedAt":…,"items":[{"task":"WEB-281","session":"local_<uuid>","sessionTitle":"Чистка документации","at":…}]}`.
Мод убирает задачу оттуда, когда она ушла из «В работе».

Заявку старше 2 минут без ответа claudibeat снимает и пишет «Ни одна сессия
Claude с модом не ответила».
